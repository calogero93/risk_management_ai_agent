# Risk Management AI Agent

Conversione del notebook originale in un progetto Python gestito con `uv`.

Il corpus contiene 15 PDF sintetici e tre file JSON. L'applicazione indicizza i PDF
con ChromaDB e BM25, estrae KPI tramite Anthropic, verifica i limiti, simula
scenari e mostra una dashboard.

Le istruzioni di esecuzione sono aggiunte insieme ai comandi del progetto.
